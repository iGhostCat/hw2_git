# Проект "Виджет банковских операций клиента"

## Описание:

Функционал данного проекта позволяет маскировать номера банковских карт и счетов,
а также сортировать журналы банковских операций по статусу их выполнения или по дате.
Добавлен функционал генерации номеров банковских карт, фильтрации банковских транзакций
по видам валют, а также вывод описания операций. Добавлен декоратор для логирования функций
с функционалом вывода логов в консоль или записи в файл
20.05.2025: Добавлен функционал конвертации транзакций в иностранных валютах в рубли с
применением внешнего API по получению данных о курсах валют:
       https://apilayer.com/marketplace/exchangerates_data-api#authentication
по видам валют, а также вывод описания операций. 
26.05.2025 Добавлен функционал приёма данных о транзакциях из файлов форматов .xlsx и .csv

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/iGhostCat/hw2_git.git
```

2. Разверните виртуальное окружение проекта:
```
pip install poetry
poetry shell
```
3. Проведите тестирование корректности работы представленного функционала:
```
pytest
```
